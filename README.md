# fecsen 홈페이지

## 개발 기술 스택
html, js, scss, react, useContext(전역관리)  
- 추가적인 라이브러리:  react-i18next(언어 변경), react-router-dom(라우팅), react-icons(아이콘)  

## 구조 및 기능
- 네이밍 방법론: BEM(Block, Element, Modifier)

- 기본 글 색상:  #3E3A39  
- 언어 설정 기능(영어, 한국어)  
- 오픈 그래프 프로토콜  

- 공통 컴포넌트: 헤더, 푸터, 사이트맵 메뉴 버튼, 사이트맵 메뉴창

## 세부 기능
- 로고: 기본 버전(흰 버전 필요)  
- 헤더: 로고, 4가지 nav, 언어 변경 버튼, fixed  
  - 로고: 클릭 시 메인 페이지로 이동  
  - 헤더 nav: 마우스 오버 시 해당하는 메뉴가 위에서 밑으로 나타남, 주황색으로 색 변경, 마우스 포인터  
  - 언어 변경 버튼 클릭 시 영어/한국어 전환 (기본은 한국어, 한국어면 EN, 영어면 KO로 표시)  
- 메뉴들: 마우스 커서 포인터, 색 변경 해당 페이지로 이동, 마우스 아웃 시 사라짐  
- 푸터: 로고, 카피라이트, 사이트맵(마우스 커서 포인터, 색 변경, 클릭 시 해당 페이지로 이동), 이메일, 연락처  
- 메인 페이지: 슬라이드 배너  

## 파일 구조

📦src  
 ┣ 📂assets // 이미지, 아이콘 등  
 ┣ 📂components // 공통 UI 컴포넌트  
 ┣ 📂pages // 각 페이지 별 jsx 파일  
 ┣ 📂styles // scss 스타일  
 ┣ 📂utils // 공통 함수  
 ┣ 📂data // 데이터 파일
